# HRsys V2.1 前端重构设计说明

## 目标

V2.1 不修改后端评价规则和接口语义，重点重构管理端与移动端的展示层，让真实业务用户能快速理解当前状态、下一步操作和风险提示。

## 设计方向

- 管理端采用“运营控制台”结构：先给批次总览和关键指标，再进入题目、关系、进度等配置/监控页面。
- 移动端采用“评价工作台”结构：首页展示待办，批次页展示任务目录，评分页展示单人卡片和固定操作。
- 两端统一使用清晰的企业级视觉语言：白色工作面、深蓝主色、青色操作强调、绿色完成、琥珀待办、红色风险。
- 所有关键操作按钮保持 44px 以上触控尺寸，底部固定操作区必须不透明，并为正文预留空间。

## 管理端改造范围

- `Layout`：重构侧边栏、顶部栏、主内容留白和页面标题。
- `Dashboard`：从简单统计表改为管理总览，展示批次状态、当前工作流入口和最近批次。
- `Batch`：突出“批次工作流”，把评估矩阵、题目、关系、进度做成清晰操作组。
- `Progress`、`Relation`、`SelfQuestion`、`User`：统一页面头部、工具栏、表格密度、状态标签和分页。

## 移动端改造范围

- `Home`：改成待办工作台，优先展示总任务、待完成、可继续批次。
- `Evaluate`：改成批次任务中心，按自评、互评、向下评价三块展示状态和入口。
- `BatchEval`：保留目录优先，强化每人状态、可评价原因和分数摘要。
- `EvalForm`、`PeerEval`、`DownwardEval`：统一评分卡片、固定顶部总分、固定底部操作，弱化无意义数字，突出题目满分和参考分。

## 验证标准

- 管理端和 H5 均能构建通过。
- 集成测试通过。
- 浏览器截图验证移动端 390x844、管理端 1440x900 不出现遮挡、透明穿透、按钮不可见。
- 页面主操作在首屏或固定底部可见，状态文字不能只靠颜色表达。
